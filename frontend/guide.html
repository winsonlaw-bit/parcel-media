这台飞轮怎么转

先看全局：一项增值服务，如何把货主、配送员与 NJV 拉进同一个正向循环。汇报时这一页讲完整个提案。

飞轮四步（文字版）
  1. 每个妥投包裹 = 一次 100% 到家的曝光：包裹物料位（物理）+ 妥投消息（数字通道）。
  2. 货主用它做新商品测品，并通过流量渠道分销实现转化增收，拿到的是增量单，不是更低的运价。
  3. 货主因此把更多货交给 NJV，议价从运价切到增量；货量回流 → 物理流量更大，回到第 1 步。
  4. 侧环：带货转化有佣金 → 配送员增收 → 吸引更多人加入 → 运力更厚，承接更多包裹。
轴：位子、通道、归因都在 NJV，别人抄不走。

货主买的是哪两种服务

同一份由妥投带出的物理流量，卖给货主两件事——先用真实到家的流量试出新品，再走一条流量渠道分销把货卖更多。

服务 01
新商品测品

这是通过包裹媒体（广告位）进行的测品：把新品放进真实到家的流量里试——按 76 个邮区各自的品类画像挑样本区，往对应包裹贴选品卡 / 二维码，妥投消息挂商品网址，按邮区看反馈。

凭什么值得做：曝光是 100% 到家的确定性事件，样本区可按邮区圈定；线上测品买的是竞价曝光，这里买的是确定性到家。扫码回流归因为方案态，待 pilot 验证。

服务 02
转化增收 · 卖更多货

这同时是一条流量渠道分销（不囤货，商家直销，NJV 只做流量扶持）：货主租位进场、无需自建投放渠道，把「高需求邮区 × 品类亲和 lift」变成动作——往对的包裹贴对的选品卡、推对的链接，把收件人池转成连带与复购。NJV 只做渠道、归因与结算，不经销、不碰货、不定价。

货主拿到的是一条新增卖货渠道 + 增量单，而不是更低运价，因此更倾向把货量交给 NJV；结算可按效果分润（设计态）。议价基础从运价切到增量，这是不内卷的关键。

三个入口，按可规模化程度分层

三种触达不是同一个量级：前两个覆盖全部妥投包裹，第三个只在有真实接触点时启用。

入口 1 · 包裹物料位（物理）
包装上的选品卡 / 二维码。随每个妥投包裹到家，100% 覆盖，放门口 / 柜的零接触场景也成立。
入口 2 · 妥投消息（数字通道）
妥投通知里放商品网址。由「妥投」这个物理事件触发，100% 覆盖、高打开率；它是数字消息，不是物理位。
入口 3 · 面对面推销（窄场景增强）
仅 COD / 冷链 / 大件等真实接触点，全 SG 可实测 COD 占 4.68%。配送员自愿、按转化提成、非 KPI，不是常态入口。
落地形态示例 · 入口 1 的联名款包裹 方案设计 · 非已合作

举例（假设场景，非已合作）：若泡泡玛特购买增值服务，NJV 用流量地图选定投放邮区，该区派送包裹换成「货主 × NJV」联名包装，包装上放商品入口二维码。两种落点 = 两种卖法：A 是专属位（单一货主买下某邮区物料位），B 是平台位（多货主共用 NJV 聚合页、分摊投放）。无论哪种，位子与扫码归因都在 NJV 侧——这正是「按邮区定向 + 租位分润」落到实物上的形态。

口径说明：规模化的投放测算与招商以前两个入口为基准；第三个作为高价值场景的补强，不按全量包裹外推。

为什么只有 NJV 转得动

飞轮的轴：三层互不重叠——广告打在哪 → 凭什么定向 → 为什么绕不开。

① 能触达什么

广告只打在由妥投带出的两类位子上——物理位（包裹物料位）与数字通道（妥投消息）。妥投消息由物理事件触发，但它是数字消息、不是物理位；两类都属于「握着包裹的人才有的物理流量」。

② 凭什么定向

发货端货主关系 + 收货端真实需求，算出 76 个邮区各自的品类画像。它决定往哪个包裹贴什么、给哪些收件人推什么，也支撑测品与招商——是情报底座，不是触点。

③ 为什么绕不开

位子、通道、归因全在 Ninja Van 控制侧：货主租位分润，扫码回流在体系内结算，情报不外泄。别人能买运力，买不到这两类位子和这套画像。

线上流量人人能买（竞价），物理流量只有握着包裹的人能卖（链主）。
这里的「物理流量」= 由妥投带出的全部触达：包裹物料位（物理）＋ 妥投消息（数字通道）。

落到飞轮上：① ② 是位子与通道，③ 是归因闭环——三者都在 NJV 控制侧，所以增量留在体系内，飞轮转起来也不会被白嫖。

四方价值 · 同一台飞轮，四方都受益

不是零和分蛋糕：货主的增量、配送员的收入、NJV 的货量与运力，由同一个循环一起做大。

① 收件人 / 消费者
按真实需求收到推荐，新品先在合适邮区小范围试，减少随机铺货的打扰。
② Shipper 货主
拿到两种服务：新商品测品与转化增收——后者也是一条可结算的流量渠道分销。得到的是新增卖货渠道与增量单，而非更低运价，谈判不再只围绕降价。
③ NJV 配送员
主流零接触包裹不参与带货；仅在真实接触场景自愿推销、按转化拿佣金增收。多一份收入机会，也吸引更多人加入网络。
④ NJV 网络
位子 + 通道 + 数据三位一体，货主租位分润；货量回流做大物理流量，配送员加入补充运力，竞争维度从运价切到增量。

诚实边界
  • 金额 / GMV / 在营商铺数一律不编，只给包裹量、收件人、邮区、货主等可溯源物理量。
  • 「联名款包裹 / 泡泡玛特」只是举例说明投放形态的假设场景，非已合作客户、非已上线物料；A / B 两种二维码落点均为方案设计。
  • 试点尚未跑通：租位分润、扫码回流归因是设计态，未做真用屏动作与回流验证。

  • 飞轮的增长箭头（货量回流、吸引加入、补充运力）是机制推演，不是已验证的增长数据；本页不提供任何金额或增幅预测。
  • 「两种服务」均为提案设计，测品反馈、流量渠道分销与转化增收尚未跑过 pilot；NJV 定位为渠道方（不经销、不碰货、不定价），页面不含成交额、转化率或分润比例实测值。

  • 框架原理性可复制、货主主数据池已跨六国；但 SG 校准参数（76 区、放门口/柜、低 COD）需逐市场本地化。
